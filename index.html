Read Aloud

Markdown is understood: # headings, **bold**, *italic*, nested lists, task lists, tables, > quotes and code blocks show up properly on the Listen tab, and the symbols are never read aloud.

Double-click (or double-tap) any word to start reading from there. Code blocks are shown but not read aloud.

Voice and timing

This device only offers basic voices. For a friendlier, more natural sound, open this page in Microsoft Edge and pick a voice marked "Natural", or in Chrome and pick a "Google" voice. On iPhone or Mac, add an Enhanced voice in Settings > Accessibility > Spoken Content > Voices.
